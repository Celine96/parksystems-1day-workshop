
# 1. 클로드 vs 클로드 코드

---

### [개념] 둘 다 "클로드"인데 뭐가 다른가요?

여러분이 평소에 쓰시는 클로드(claude.ai 채팅창)와, 오늘 배울 **클로드 코드**는 **같은 회사(Anthropic)의 같은 AI**예요. 다만 **실행 환경이 달라요**.

- **클로드 (claude.ai)** — 웹 브라우저에서 실행돼요. 우리는 대화로 일을 시키죠.
- **클로드 코드** — 내 컴퓨터 터미널에서 실행돼요. 내 폴더와 파일을 직접 보고, 만들고, 고칠 수 있어요.

쉽게 말하면:

> **클로드 = 상담사** (창문 너머로 대화)
> **클로드 코드 = 우리 집에 출근한 에이전트** (직접 책상 정리, 문서 작성)

알아야 할 명령어는 딱 하나예요: `claude`

### [개념] 뭐가 다른가요? — 5가지 비교

각 항목을 좀 더 풀어볼게요.

1. **파일 접근**: 클로드는 우리가 파일을 채팅창에 업로드해야 봐요. 클로드 코드는 우리 컴퓨터 폴더를 직접 들여다봐요 — 마치 책상에 앉은 동료처럼요.

2. **기억력**: 클로드는 대화창을 닫으면 다 잊어요. 클로드 코드는 `CLAUDE.md`라는 메모장에 프로젝트 정보를 저장해서 다음에도 기억해요.

3. **실행력**: 클로드는 우리가 한 줄 물으면 한 줄 답해요. 클로드 코드는 "이 폴더 정리해줘" 같은 큰 목표를 받으면 스스로 단계를 쪼개서 끝까지 처리해요.

4. **동시 작업**: 클로드는 한 가지씩 순서대로 해요. 클로드 코드는 여러 일을 동시에 굴릴 수 있어요.

5. **에이전트**: 클로드는 만능 AI 한 명이에요. 클로드 코드는 "PM 에이전트" "매뉴얼 작가 에이전트"처럼 역할별로 전문 에이전트를 두고 분업할 수 있어요. (오늘 두 개 만들 거예요!)

> **핵심 차이**: 클로드도 일상 업무에 충분히 쓸 수 있어요. 다만 새 대화를 시작할 때마다 프로젝트 맥락·선호사항·용어를 매번 다시 설명해야 해요. 이걸 **재설명 문제(Re-Explanation Problem)** 라고 해요. 클로드 코드는 `CLAUDE.md`에 이 정보를 저장해두니까, 매번 처음부터 설명할 필요 없이 바로 작업을 이어갈 수 있어요.
