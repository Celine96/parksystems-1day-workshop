
# 1. Claude AI vs Claude Code vs Claude Co-work

> 같은 회사(Anthropic)의 Claude 제품군에는 세 가지 다른 환경이 있어요.

---

## [개념] Claude 제품군 — 사고·구축·실행

Anthropic은 같은 Claude AI를 세 가지 다른 환경으로 제공해요. 같은 프롬프트("월간 판매 보고서 읽고 상위 5가지 통찰력 요약")라도 제품에 따라 결과가 다릅니다.

<SectionTitle title="Claude.ai" sub="대화 중심 / 생각 도구" />

> - **위치** — 웹 브라우저
> - **하는 일** — 구조·문구·추론 도움 → 생각의 틀 제공
> - **잘 맞는 일** — 질문·탐색·초안 작성·분석

<SectionTitle title="Claude Code" sub="기술 환경 / 실행 도구" />

> - **위치** — 터미널 (내 컴퓨터)
> - **하는 일** — 파일·코드·스크립트 직접 다룸 → 코드/파일 결과물
> - **잘 맞는 일** — 코딩·디버깅·테스트·시스템 수정

<SectionTitle title="Claude Co-work" sub="비즈니스 도구 / 실행 도구" />

> - **위치** — 데스크톱 + Slack·문서·이메일
> - **하는 일** — 보고서 찾고·열고·요약본 작성 → 업무 완료
> - **잘 맞는 일** — 파일 처리·작업 조정·반복 다중 작업

**핵심 차이**:
- **Claude.ai**는 작업을 **생각하도록** 돕는다.
- **Claude Code / Co-work**은 작업을 **완료하는 방향**으로 가요.

## [개념] AI가 일하는 방식의 시대 흐름

AI 도구는 시대별로 **달성하려는 목적**이 달라졌어요.

> **🗓️ 2023 — Prompt 시대**
> - 핵심: "프롬프트를 잘 쓰면 좋은 답이 나옴"
> - 도구: ChatGPT, Claude 채팅, Gemini
> - 우리가 한 일: **한 줄 잘 쓰기**

> **🗓️ 2025 — Context 시대**
> - 핵심: "관련 자료(코드·문서·이미지)를 다 넘겨주면 더 좋은 답"
> - 도구: Cursor, Manus
> - 우리가 한 일: **자료 다 모아주기**

> **⭐ 2026 — Harness 시대** (← 오늘 우리가 할 일)
> - 핵심: "AI가 일할 작업 환경 자체를 잘 짜기"
> - 도구: Claude Code, Codex
> - 우리가 할 일: **운영 시스템 만들기** (폴더·커맨드·에이전트 정의)

## [개념] 왜 우리는 오늘 클로드 코드를 사용할까요?

<SectionTitle icon="🌐" title="AI Native 흐름" sub="비개발자도 기획부터 구현까지" />

> - 비개발자 도메인의 사람들도 터미널 허들만 한 번 넘기면, **기획-구현-검수 에이전트들을 개별로 만들어 loop로 완성도 있는 결과물**을 만들어내는 추세
> - 다양한 제품의 **MCP 연동성**과 **스킬 제작**으로 Claude Code에서 기획부터 구현까지 AI Native로 업무 자동화·위임이 가능

<SectionTitle icon="✅" title="Claude Code의 강점" sub="파일·자체 처리·md 전달" />

> 오늘 4시간은 **Claude Code**에 집중해요. 이유:
>
> - 매뉴얼·기술 문서·자료 분석 작업이 **파일과 폴더 중심**
> - 회사 내부 자료를 외부 도구 안 거치고 **내 컴퓨터에서 직접** 처리
> - 한 번 만든 에이전트가 **다음 사람에게 그대로 전달 가능** (md 파일 단위로)

> 💡 오늘 만들 두 에이전트 (PM 에이전트 + 에디터 에이전트)도 이 패턴의 작은 예시. 본격 적용 시 Planner / Generator / Evaluator 3-에이전트로 확장 가능 (부록 3 참고).
