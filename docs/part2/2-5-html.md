# 7. 프로젝트 #4.2 : HTML 변환

> 우리가 만든 매뉴얼을 누구나 볼 수 있는 **웹페이지 형태**로 변환해보는 시간이에요. 6번 마지막 5분에 봤던 HTML 미리보기를 본격적으로 다뤄봅니다.

---

## [도입] 왜 HTML로 만드나요?

회사 매뉴얼이 .docx·.pdf 파일로만 있으면 받는 사람이 다운로드해서 봐야 해요.

<p style="font-size: 1.2em; font-weight: 700; color: var(--vp-c-brand-1); margin: 24px 0 8px;">✅ HTML 웹페이지로 만들면 <span style="color: var(--vp-c-text-2); font-weight: 400; font-size: 0.85em;">— 받는 사람이 다운로드 없이 바로 보기</span></p>

> - URL 한 줄로 공유
> - 모바일·태블릿·PC 모두 잘 보임
> - 검색 가능
> - 누구나 보기 좋음

---

## [실습] publish-manual 슬래시 커맨드 만들기

매뉴얼을 자주 HTML로 바꿀 거니 슬래시 커맨드로 만들어둘게요.

대화창에 입력:

```
.claude/commands/publish-manual.md 파일을 새로 만들어줘.

내용은 이렇게:

---
description: 매뉴얼 .md 파일을 보기 좋은 HTML 페이지로 변환하기
---

사용자가 .md 파일 경로를 주면, 다음 스타일로 HTML로 변환해서 같은 폴더에 저장해줘:

- 회사 매뉴얼 톤 (격식 있는 영문 페이지 느낌)
- 챕터 제목 강조 (h1, h2 스타일)
- 본문 가독성 좋은 폰트·줄 간격
- 표·코드 블록 깔끔하게
- 모바일 반응형
- 인쇄해도 깔끔하도록 print CSS 포함

저장 파일명: 원본.md 와 같은 이름의 .html
```

이제 `/publish-manual [파일 경로]` 한 줄로 HTML 변환 가능.

---

## [옵션 A] 로컬에서 보기

가장 단순한 방법. 본인 컴퓨터에서만 봐요.

```
/publish-manual 5_매뉴얼/output/Chapter1_Intro.md
```

생성된 `Chapter1_Intro.html` 파일을 Nimbalyst나 파일 탐색기에서 **더블클릭** 하세요. 기본 브라우저에서 깔끔한 웹페이지로 열려요.

> 💡 **포인트**: 본인만 보거나, 메일에 첨부할 때 충분해요.

---

## [옵션 B] 인터넷에 띄우기 — Netlify Drop

회사가 아닌 인터넷에 띄워서 URL로 공유하는 방법. **가입 없이 1분이면 가능**해요.

> ⚠️ **주의**: 회사 내부 매뉴얼·고객 정보가 들어간 자료는 **외부 호스팅 X**. 공개해도 되는 자료(일반 교육·공개 안전 가이드·포트폴리오 등)에만 사용하세요.

**Step 1.** 브라우저에서 https://app.netlify.com/drop 접속.

**Step 2.** HTML 파일이 든 폴더(`5_매뉴얼/output/`)를 화면에 **드래그앤드롭**.

**Step 3.** 임시 URL 자동 생성. 클립보드에 복사해서 공유하면 끝.

> 💡 **포인트**: 가입(이메일 한 줄)하면 영구 URL + 본인 도메인 연결 가능. **Vercel**도 비슷한 방식 — 8번 부록에서 안내.
