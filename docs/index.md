## 워크북 사용법

이 워크북은 **직접 따라 하며 배우는 실습 중심** 자료예요.

- **[개념]** → 읽고 이해하는 부분
- **[실습]** → 직접 손으로 해보는 부분
- **[체크포인트]** → "여기까지 됐나" 진척 확인
- 막히면 언제든 질문하세요!

> **소요 시간**: 4시간 (0교시 30분 + 본 수업 195분 + 마무리)
> **준비물**: 개인 노트북, 인터넷 연결, Claude Pro 또는 Max 구독
> **사전 지식**: 코딩 경험 X, 터미널 경험 X

| 시간 | 챕터 | 무엇을 해요 |
|---|---|---|
| 0교시 (30분) | 1.1 + 1.2 | 클로드 코드가 뭔지 이해하고 설치 |

| 2교시 (90분) | 2.2 PM 에이전트 | 문서를 읽고 진행 상황 보고하는 비서 만들기 |
| 3교시 (75분) | 2.3 + 2.4 매뉴얼 자동 생성 | 회사 문체로 매뉴얼 작성 + 학술 근거 자동 수집 |
