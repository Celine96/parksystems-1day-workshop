## 워크북 사용법

이 워크북은 **직접 따라 하며 배우는 실습 중심** 자료예요.

- **[개념]** → 읽고 이해하는 부분
- **[실습]** → 직접 손으로 해보는 부분
- **[체크포인트]** → "여기까지 됐나" 진척 확인
- 막히면 언제든 질문하세요!

> **소요 시간**: 4시간 (시작 30분 + 메인 195분 + 마무리)
> **준비물**: 개인 노트북, 인터넷 연결, Claude Pro 또는 Max 구독
> **사전 지식**: 코딩 경험 X, 터미널 경험 X
